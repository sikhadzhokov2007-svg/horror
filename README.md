# Night Shift

Первый прототип одиночного 3D survival horror для Windows на **Unity 6**. Игрок — бывший ученик, проникший ночью в школу, чтобы выяснить правду о старом охранном роботе. Цель — дожить до утра, исследовать корпуса, собирать предметы и избегать синего аниматроника-лиса.

## Что уже реализовано

- first-person персонаж: ходьба, бег, прыжок, приседание и обзор мышью;
- взаимодействие с дверьми по клавише `E`;
- автоматически создаваемый во время запуска blockout: вестибюль, длинный коридор, три класса, свет и интерактивные двери;
- исходники C# без платных ассетов и без обязательных пакетов.

## Установка Unity бесплатно

Скачайте **Unity Hub** с официальной страницы: [unity.com/download](https://unity.com/download). В Unity Hub установите Unity 6 (LTS) с модулем **Windows Build Support (IL2CPP)**.

## Запуск проекта

1. Откройте Unity Hub и нажмите **Add → Add project from disk**.
2. Выберите папку, где лежат `Assets`, `Packages` и `ProjectSettings`.
3. Откройте проект версией Unity 6.
4. В Unity нажмите **Edit → Project Settings → Player** и в поле **Active Input Handling** выберите **Both**. Unity попросит перезапустить редактор — согласитесь.
5. В окне **Project** откройте любую сцену или создайте пустую: **File → New Scene → Basic (Built-in)**, затем сохраните её.
6. Нажмите **Play**. Скрипт bootstrap сам создаст игрока и черновую школу.

| Бег | `Left Shift` |

| Прыжок | `Space` |
| Открыть/закрыть дверь | `E` |
