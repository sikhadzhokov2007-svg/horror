# Night Shift

Первый прототип одиночного 3D survival horror для Windows на Unreal Engine 5. Игрок — бывший ученик, проникший ночью в школу, чтобы выяснить правду о старом охранном роботе. Его цель — дожить до утра, исследовать корпуса, собирать предметы и избегать синего аниматроника-лиса.

## Уже реализовано в каркасе

- first-person персонаж: ходьба, бег, прыжок, приседание;
- взаимодействие с дверьми (`E`);
- создаваемый во время запуска blockout: вестибюль, длинный коридор и три класса;
- настройка управления и игровой режим C++.

## Быстрый запуск

1. Установите Unreal Engine 5.6 через Epic Games Launcher.
2. Откройте `NightShift.uproject`; если редактор предложит собрать модули — согласитесь.
3. Нажмите **Play** в редакторе.

### Управление

| Действие | Клавиша |
| --- | --- |
| Движение | `W A S D` |
| Осмотр | мышь |
| Бег | `Left Shift` |
| Присесть | `Left Ctrl` |
| Прыжок | `Space` |
| Открыть/закрыть дверь | `E` |

Подробный дизайн и следующий этап находятся в [документе дизайна](Docs/GameDesign.md).
